## Multiplicación de matrices  
Se realizó la multiplicación de matrices cuadradas y no cuadradas utilizando paralelismo mediante MPI. Para ello, se programaron dos implementaciones, una secuencial y una paralela. Posteriormente, se realizaron diversos experimentos con diferentes tamaños del problema y diferente número de nodos para cuantificar la ganancia obtenida con el paralelismo, evaluando métricas como el speedup, la eficiencia, el balanceo de carga y la escalabilidad.
